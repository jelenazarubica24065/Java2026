# OOP – Kompletna zbirka vježbi (Eclipse IDE projekat)

Objedinjeni **Eclipse IDE** projekat koji sadrži sve prethodno pripremljene zadatke (Vježbe 1 i 2 + klase, objekti i statički članovi) i nove zadatke (klase i objekti + nizovi).

## Struktura paketa (`src/`)

### Vježbe 1 i 2
* `vjezbe1`: `NajveciNajmanji.java` (V1-6), `BrojPozitivnihNegativnih.java` (V1-7)
* `vjezbe2`: `NasAbs.java` (V2-1), `Fja.java` (V2-2), `Faktorijel.java` (V2-3), `Cifre.java` (V2-4)
* `vjezbe2_dodatni`: `Blago.java` (VII-1), `TajnaVrata.java` (VII-2), `ParanPozitivan.java` (VII-3), `Mjesec.java` (VII-4), `Zavjesa.java` (VII-5), `FizzBuzz.java` (VII-6), `Potrosnja.java` (VII-7), `Narcisoid.java` (VII-8), `Parking.java` (VII-9), `Dron.java` (VII-10), `Mravi.java` (VII-11)

### Klase, objekti i statički članovi
* `zadatak1_kompleksni`: `KompleksniBroj.java`, `KompleksniBrojTest.java`
* `zadatak2_staticki_kompleksni`: `KompleksniBroj.java`, `KompleksniBrojTest.java`

*(Napomena: zadaci koji su u materijalu navedeni samo kao naslovi bez koda nisu ubačeni.)*

## Otvaranje u Eclipse IDE
1. Raspakuj projekat u svoj `eclipse-workspace` folder.
2. U Eclipse-u izaberi **File → Import → General → Existing Projects into Workspace**, označi `OOP_Vjezbe_Komplet` i klikni **Finish**.
